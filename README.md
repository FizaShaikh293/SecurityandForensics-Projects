## 🚨 Featured Projects

### 🕵️ Log Detective | SOC Investigation Game

**Turn security logs into a game.**

Log Detective is a browser-based SOC investigation game where players analyse security events, identify suspicious behaviour, classify threats, avoid false positives and progress through SOC analyst ranks.

The game includes scenarios involving:

- 🔨 Brute-force attacks
- 🎣 Phishing
- ⚡ Suspicious PowerShell activity
- 👤 Rogue administrator accounts
- 🦠 Ransomware indicators
- 👨‍💻 Legitimate user behaviour

**Tech Stack:**  
`React` `JavaScript` `Vite` `Framer Motion` `Lucide React` `HTML` `CSS` `JSON` `Vercel`

🎮 [Play Log Detective](https://lnkd.in/dPRZWcTK)

💻 [View Project](./Log-Detective)

> SIEM logs, but with XP and dramatic neon lighting. 💚

### 🛡️ SOC Monitoring Lab

A hands-on virtual SOC environment built to practise **endpoint monitoring, security event analysis, threat hunting and investigation**.

The lab uses **Wazuh, Windows 11, Sysmon, Kali Linux and VirtualBox**.

During the project I:

- Set up a virtualised SOC environment
- Configured a Windows endpoint for monitoring
- Integrated Windows telemetry with Wazuh
- Monitored and investigated security events
- Used Wazuh Threat Hunting
- Investigated Windows security events, including **Event ID 5157**
- Reviewed endpoint and command-line activity

**Tech Stack:**  
`Wazuh` `Windows 11` `Sysmon` `Kali Linux` `VirtualBox` `Windows Event Logs`

🔍 [View SOC Monitoring Lab](./soc-monitoring-lab)

### 🌐 Directory Traversal Attack Simulation

A hands-on web application security project exploring how improper input validation can lead to **directory traversal vulnerabilities**.

The project demonstrates how manipulated file paths can be used to access files outside an application's intended directory and explores defensive approaches to the vulnerability.
