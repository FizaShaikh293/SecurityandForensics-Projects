# 🔎 Log Detective

A browser-based SOC investigation game where players analyse security logs, identify suspicious activity, and classify potential threats.

## 🕵️ What You'll Investigate
- Brute-force login attempts
- Suspicious authentication activity
- PowerShell execution
- New administrator accounts
- Multiple failed logins
- Normal vs malicious activity

## 🛠 Tech Stack
- React
- Vite
- JavaScript
- HTML/CSS
- Node.js / npm
- Vercel

## 🚀 Live Demo
[Play Log Detective](https://log-detective.vercel.app/)

## 💻 Run Locally

npm install
npm run dev

## 🎯 Why I Built It

I wanted to turn SOC log analysis into something more interactive than simply reading rows of logs which gives users a small taste of investigating events, gathering evidence, and making security decisions.
